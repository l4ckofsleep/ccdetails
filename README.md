# session-meter

Мод для Claude Code: компактная сворачиваемая панель над полем ввода, где видно всё, что обычно приходится выковыривать из `/context` и `/cost`:

```
Сессия                                                    ▾ свернуть
Контекст  ███░░░░░░░░░░░  25%  128k / 512k · модель 1M
Кеш       █████████████░  97%  за сессию 91% · 1.2M из 1.3M · 37 запр.
5ч        █████░░░░░░░░░  34%  сброс через 2ч 10м
7д        ██░░░░░░░░░░░░  12%  сброс через 3д 4ч
Расход    $4.21
```

В свёрнутом виде это одна строка: `▸ ctx 25% · cache 97% · $4.21 · 5ч 34%`.

*English TL;DR: a collapsible band above the Claude Code prompt showing context fill (against your effective auto-compact window), prompt-cache hit %, rate-limit windows with reset countdowns, and session cost.*

## Что показывает

| Строка | Откуда | Примечание |
| --- | --- | --- |
| **Контекст** | `$.session.usage()` | Процент считается от **действующего** лимита: `autoCompactWindow` из настроек или `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, иначе окно модели. Если лимит меньше окна модели, рядом показано и оно. |
| **Кеш** | `usage` каждого запроса к модели (`turn.step`) | Полоса показывает hit% **последнего** запроса, по ней сразу видно, что кеш протух. Справа hit% за сессию. Формула: `cache_read / (input + cache_read + cache_creation)`. |
| **5ч / 7д** | rate-limit окна из последнего ответа API | С отсчётом до сброса. На API-ключе без подписки строк нет. |
| **Расход** | `$.session.usage().cost` | В долларах, как в `/cost`. |

Цвета: контекст и лимиты до 60% зелёные, до 85% жёлтые, выше красные. Кеш наоборот: от 80% зелёный, от 50% жёлтый, ниже красный.

Данные обновляются после каждого запроса к модели и раз в минуту.

## Установка

Нужен Claude Code с поддержкой модов (function hooks). Проверено на **2.1.293–2.1.295**. API модов пока в early access и может меняться между релизами.

### Вариант 1. Одной командой (терминал)

В интерактивной сессии `claude` в терминале:

```
/plugin install session-meter --marketplace l4ckofsleep/ccdetails
```

1. На вопрос `Add marketplace?` ответь `y`.
2. Выбери scope **user**, чтобы мод работал во всех проектах.
3. Мод включится сразу, перезапуск не нужен.

Мод, поставленный так на уровне user, работает и в сессиях Code-вкладки десктопного приложения Claude. Сама команда `/plugin` там недоступна, поэтому ставить нужно из терминала.

Обновление:

```bash
claude plugin update session-meter
```

### Вариант 2. Из клона через `CLAUDE_CODE_PLUGIN_DIRS`

Подходит, если хочешь править мод под себя.

```powershell
git clone https://github.com/l4ckofsleep/ccdetails.git "$env:USERPROFILE\.claude\mods\session-meter"
```

Добавь путь в `~/.claude/settings.json` (несколько папок разделяются `;` на Windows и `:` на macOS/Linux):

```json
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "C:\\Users\\<you>\\.claude\\mods\\session-meter"
  }
}
```

Переменная читается при старте сессии, так что мод появится в новых сессиях. Обновление: `git pull` в папке мода.

### Разовый запуск без установки

```bash
claude --plugin-dir ./session-meter
```

## Управление

- **▾ свернуть / ▸** сворачивает и разворачивает панель.
- Встроенный `[-]` справа от панели (или `ctrl+x ctrl+a` в терминале) прячет её целиком.

## Ограничения

- Кеш считается только по основному потоку. Сабагенты держат свои кеши и в процент не входят.
- Счёт кеша начинается с момента загрузки мода. Запросы, сделанные раньше в той же сессии, не учитываются.
- Свёрнутое состояние живёт до конца сессии.

## Разработка

```bash
claude plugin validate .
claude plugin test .
```

Тест (`hooks/meter.test.ts`) прогоняет подсчёт кеша, лимит контекста, отсчёт сброса и сворачивание на поверхностях `terminal` и `desktop`. Типы API движок кладёт в `.claude-plugin/types/` при загрузке мода. После этого `tsc -p .` проверяет типы.
